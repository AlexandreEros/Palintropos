# Williamson 5 comparison products

This directory holds compact T42 and T63 trajectory extracts, completion
records, day-zero checks, comparison metrics, and
[rendered comparisons](figures/README.md). [plot_swe_holistic.py](plot_swe_holistic.py)
builds the comparison figures. The short [verification run](smoke/README.md)
records the smoke check. The [canonical validation report](../williamson5_mri_2026-07-30.md)
explains the field definitions, acceptance envelopes, and preserved inputs.
