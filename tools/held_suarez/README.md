# Held–Suarez evidence tools

- [dino_reference.py](dino_reference.py) and [dino_b2.py](dino_b2.py) prepare
  the external Dinosaur reference and B2 data.
- [compare_runs.py](compare_runs.py) and [mass_budget.py](mass_budget.py)
  compare archived runs and diagnose mass behavior.
- [tier_a_evidence.py](tier_a_evidence.py) computes Tier A evidence.
  [climate_fixture.py](climate_fixture.py) builds the compact test fixture.

See the [Held–Suarez protocol and acceptance record](../../docs/held_suarez/README.md)
for experiment settings and criteria. Each script documents its inputs and
outputs in its module docstring.
